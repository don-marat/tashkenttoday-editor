# Tashkent Today - Гибридный AI-Редактор для Telegram

Гибрид на основе:
- `rakinsv/telegram-admin-app-project` (двух-агентная редакция: журналист + редактор)
- `tbogdan2001/news-poster` (структура заголовок + саммари + хештеги)
- Твой эталон из скриншотов (строгий стиль, коротко, 3 альтернативных заголовка)

## Структура проекта

```
/prompts/
  01_journalist.md      -> Агент 1: пишет черновик новости из сырого текста
  02_editor.md          -> Агент 2: факт-чекер, режет воду
  03_title_gen.md       -> Агент 3: генератор 3-х цепляющих заголовков
  SYSTEM_FINAL.md       -> Итоговый промт (если нужен 1 бот вместо 3-х агентов)

/bot.py                 -> Пример Telegram-бота (python-telegram-bot + OpenAI)
/config.yaml            -> Настройки канала
```

## Как это работает в Telegram-группе

1. Тебе кидают сырой текст / пресс-релиз / ссылку
2. Бот прогоняет его через 3 роли (или через 1 итоговый SYSTEM_FINAL)
3. В группу падает готовая новость в формате как на твоем скрине

## Установка

1. Создай бота в @BotFather, получи TOKEN
2. Добавь бота в рабочую группу как админа
3. Установи зависимости: `pip install python-telegram-bot openai pyyaml`
4. В .env пропиши:
```
BOT_TOKEN=...
OPENAI_API_KEY=...
GROUP_ID=-100...
```
5. Запусти: `python bot.py`
